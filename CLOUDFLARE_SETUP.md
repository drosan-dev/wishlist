# Подключение общей брони и анонимных сообщений

Для личного вишлиста достаточно бесплатного плана Cloudflare Workers + D1.

## Что понадобится

1. Бесплатный аккаунт на `dash.cloudflare.com`.
2. Создать D1-базу с именем `anton-wishlist`.
3. Применить файл `worker/schema.sql`.
4. Скопировать `worker/wrangler.toml.example` в `worker/wrangler.toml` и вставить ID базы.
5. Создать секрет `GIFT_HASH_SECRET` — длинную случайную строку. Он нужен, чтобы даже в таблице не хранить понятные названия выбранных подарков.
6. Опубликовать Worker и сохранить его адрес вида `https://anton-wishlist-api.<account>.workers.dev`.
7. В GitHub открыть Settings → Secrets and variables → Actions → Variables и добавить `NEXT_PUBLIC_API_URL` с адресом Worker.
8. Повторно запустить workflow GitHub Pages.

## Что будет видно

- Посетители видят только «Свободно» или «Уже выбрали».
- Для отмены бронь один раз выдаёт секретный код; в базе хранится только его хеш.
- Название подарка в базе заменяется HMAC-ключом, поэтому случайный просмотр таблицы не раскрывает сюрприз.
- Текст анонимного вопроса хранится в D1 без имени, почты или VK.

Перед публичным запуском стоит добавить Cloudflare Turnstile и rate limit для формы сообщений.
